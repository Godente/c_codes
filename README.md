# C_Codes Repository

This repo contains various Ⓒ scripts to work with matrixes and vectors, in the near future i'll add machine and deep learning scripts also in Ⓒ.

## Getting Started
To compile and run the programs, use:
```sh
gcc-14 source_file.c library.c -o program_name
./program_name
```
if the library.c, and its header, are in the folder "lib", use:
```sh
gcc-14 source_file.c lib/library.c -Ilib -o program_name
./program_name
```
